# 客家小錢地圖 Web App 需求規格書

## 專案概述

### 專案名稱
客家小錢地圖 Web App

### 專案目標
建立一個互動式地圖網頁應用程式，展示客家相關商家資訊，提供使用者便利的商家搜尋與導航功能。

### 目標使用者
- 尋找客家特色商家的一般消費者
- 對客家文化有興趣的觀光客
- 希望支持客家商家的社群成員

## 功能需求

### 核心功能

#### 1. 地圖顯示功能
- **FR-001**: 系統應使用開源地圖解決方案顯示互動式地圖
- **FR-002**: 商家應以錨點（markers）形式顯示在地圖上
- **FR-003**: 地圖應支援縮放、拖拽等基本操作

#### 2. 商家資訊展示功能
- **FR-004**: 點擊錨點後應彈出商家詳細資訊面板
- **FR-005**: 商家資訊應包含：名稱、介紹、地址、聯絡方式、營業時間、圖片
- **FR-006**: 商家地址應可點擊，點擊後開新頁面跳轉至 Google Maps

#### 3. 搜尋功能
- **FR-007**: 提供商家名稱搜尋功能
- **FR-008**: 提供商家地址搜尋功能
- **FR-009**: 搜尋結果應即時顯示，支援模糊搜尋
- **FR-010**: 搜尋結果應在地圖上高亮顯示

#### 4. 篩選功能
- **FR-011**: 提供縣市篩選功能
- **FR-012**: 篩選結果應即時更新地圖顯示
- **FR-013**: 應支援多個篩選條件同時使用

### 資料功能
- **FR-014**: 系統應讀取並解析現有的商家 JSON 資料檔案
- **FR-015**: 支援 1350 筆商家資料的顯示與操作

## 非功能需求

### 效能需求
- **NFR-001**: 地圖初始載入時間應小於 3 秒
- **NFR-002**: 搜尋回應時間應小於 1 秒
- **NFR-003**: 支援同時顯示所有商家錨點而不影響效能

### 使用性需求
- **NFR-004**: 介面應符合直覺操作原則
- **NFR-005**: 支援桌面和行動裝置響應式設計
- **NFR-006**: 應提供清楚的視覺回饋（loading、hover 等狀態）

### 相容性需求
- **NFR-007**: 支援主流瀏覽器：Chrome、Firefox、Safari、Edge
- **NFR-008**: 支援行動裝置瀏覽器

### 可維護性需求
- **NFR-009**: 程式碼應遵循 Vue 3 最佳實踐
- **NFR-010**: 應使用 TypeScript 提升程式碼品質
- **NFR-011**: 元件化設計，提升程式碼重複使用性

## 使用者故事

### 作為一般使用者
- 我希望能在地圖上看到所有客家商家的位置，以便規劃我的行程
- 我希望能點擊商家錨點查看詳細資訊，以便了解商家特色
- 我希望能直接從商家資訊跳轉到 Google Maps，以便獲得導航路線

### 作為搜尋使用者
- 我希望能搜尋特定商家名稱，以便快速找到目標商家
- 我希望能搜尋特定地址，以便找到附近的商家
- 我希望搜尋結果能即時顯示，以便提升使用體驗

### 作為篩選使用者
- 我希望能按縣市篩選商家，以便專注於特定區域
- 我希望篩選結果能立即更新，以便快速瀏覽

## 系統限制

### 技術限制
- 必須基於現有的 Vue 3 + Vite 架構
- 必須使用開源地圖解決方案
- 商家資料來源為靜態 JSON 檔案

### 資料限制
- 商家資料結構固定，包含：id、name、introduction、image、tag、address、contact、business_hours、map_url、classification、is_hakka、website
- 總計 1350 筆商家資料

### 功能限制
- 不包含商家資料的新增、修改、刪除功能
- 不包含使用者註冊、登入功能
- 不包含商家評論、評分功能

## 驗收標準

### 地圖功能驗收
- [ ] 地圖能正常載入並顯示台灣地區
- [ ] 所有商家錨點能正確顯示在對應位置
- [ ] 錨點點擊能正常彈出商家資訊

### 搜尋功能驗收
- [ ] 商家名稱搜尋能返回正確結果
- [ ] 地址搜尋能返回正確結果
- [ ] 搜尋結果能在地圖上正確高亮

### 篩選功能驗收
- [ ] 縣市篩選能正確過濾商家
- [ ] 篩選結果能即時更新地圖顯示

### 導航功能驗收
- [ ] 地址點擊能正確開啟 Google Maps
- [ ] Google Maps 能顯示正確的商家位置
